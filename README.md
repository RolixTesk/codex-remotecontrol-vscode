# Codex Live Remote

在手机 ChatGPT 中继续使用 VS Code 的 Codex，查看进度、发送消息、引导或停止任务、处理审批，桌面同步显示结果。

一次连接对应一个 Codex 实例，手机可选择其中的聊天。启动远程控制前只需启动 Codex，无需打开某个会话或项目。

支持 Ubuntu 本地 VS Code、Windows 本地 VS Code + WSL Codex，以及 Remote-WSL 窗口。需要 VS Code 1.118 或更新版本、官方 Codex 扩展和 Linux 环境中的 Python 3。配置可在未登录时完成；使用手机远程控制前需登录官方 Codex。当前不支持 Windows 原生 Codex 接入。

## 安装与首次使用

在 VS Code 扩展视图点击 `…` → **从 VSIX 安装…**，选择 `codex-live-remote-0.1.11.vsix`。Ubuntu 或 Windows 本地窗口安装到本地，Remote-WSL 窗口安装到 WSL。

从 0.1.9 或更早版本升级时，先卸载发布者为 `rolix` 的旧扩展，保留已有 Codex 启动设置，再安装发布者为 `RolixTesk` 的新版。等任务结束后重载窗口即可继续使用。

1. 按 `Ctrl+Shift+P`，运行 **Codex Remote: 配置远程控制**。
2. 等当前任务结束，运行 **Developer: Reload Window**。
3. 启动 Codex，运行 **Codex Remote: 配对手机**。
4. 用手机扫码或输入配对码，完成授权后选择聊天。

配对页会自动尝试在浏览器打开。浏览器未打开时，点击通知中的 **复制网页链接**，粘贴到电脑浏览器即可查看。

## 日常使用

自动连接默认开启。完成手机配对后，启动 Codex 即会自动启动远程控制，已有手机无需再次配对。有多个实例时，运行 **启动远程控制** 选择要使用的 Codex。

从旧版升级、已有手机配对却未自动启动时，手动运行一次 **启动远程控制** 即可记住已有配置，无需重新配对。

点击状态栏或运行 **查看远程控制状态** 查询最近结果。运行 **停止远程控制** 结束手机连接，桌面任务继续执行，本次窗口运行期间不会自动重新连接；手动启动或重新打开窗口后恢复自动连接。切换实例前先停止原实例的远程控制。

如需一直手动启动，在 VS Code 设置中搜索 `codexRemote.autoConnect` 并关闭。

官方 Codex 升级后的配置会自动更新；收到更新提示时，在任务结束后重载窗口。需要手动修复时运行 **配置远程控制**。

卸载前运行 **恢复 Codex 启动设置（卸载前）**，等任务结束后重载，再卸载插件。恢复的是首次配置前的设置。

完整操作说明见 [使用文档](doc/README.md) 和 [命令说明](doc/commands.md)。

## 实现方式

本插件通过官方 Codex 的 Remote 功能，将手机 ChatGPT 连接到 VS Code 已启动的 Codex，复用官方的登录、配对和远程控制能力。
