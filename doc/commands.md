# 命令说明

适用于 Codex Live Remote 0.1.7。按 `Ctrl+Shift+P`，输入 `Codex Remote` 查找命令。

## 插件命令

| 命令 | 效果 | 适用时机 |
|---|---|---|
| 配置远程控制 | 完成首次使用的配置并备份原启动设置 | 首次使用、手动修复 |
| 启动远程控制 | 让手机可以远程操作 Codex | 日常使用 |
| 配对手机 | 启动远程控制并生成手机配对页 | 添加手机或重新配对 |
| 查看远程控制状态 | 查询远程控制是否启动，更新状态栏 | 查看当前连接情况 |
| 停止远程控制 | 结束手机连接，桌面任务继续运行 | 停用手机连接、切换实例 |
| 恢复 Codex 启动设置（卸载前） | 恢复启用前的 Codex 启动设置 | 停用或卸载插件 |

## 配置远程控制

首次使用时运行一次，完成配置并备份原 Codex 启动设置。Windows 本地窗口需要官方 Codex 已启用通过 WSL 运行。

完成后状态栏显示“等待重载”。等任务结束，运行 **Developer: Reload Window**，再打开 Codex 并运行 **启动远程控制**。当前任务继续运行，新设置在后续启动时生效。

官方扩展升级后的配置会自动更新；收到更新提示时空闲重载即可。无需每次手动配置，首次保存的恢复备份会保留。

## 启动远程控制

Codex 启动并就绪后即可连接，无需打开聊天或项目。只有一个可用实例时直接连接；多个实例时选择要使用的 Codex，列表会显示启动目录和任务状态以便区分。取消选择会结束本次操作。

连接完成后状态栏显示“已启动”。手机在 ChatGPT 的 Codex / Remote 中选择主机和聊天；要继续桌面任务，选择桌面正在使用的聊天。

已启动时重复运行会保留原连接。另一个实例已启动远程控制时，先在原实例运行 **停止远程控制** 再切换。重载或关闭窗口后，需要重新运行 **启动远程控制**。

## 配对手机

首次添加手机或需要重新配对时运行。命令启动远程控制，申请一次新配对码，生成包含主机、二维码、手动码和有效期的页面，并尝试用默认浏览器打开。

浏览器未打开时，点击通知中唯一的 **复制网页链接**，将地址粘贴到电脑浏览器查看配对页。该地址用于在本机打开已生成的页面；手机使用页面上的二维码或手动码。复制链接不会再次申请配对码。

手机确认后才完成授权。已有配对的日常使用运行 **启动远程控制** 即可；每次重新运行 **配对手机** 都会申请新码。

通知未关闭或链接复制失败时，仍可运行其他插件命令。关闭通知不会停止远程控制。

## 查看远程控制状态

读取远程控制状态并更新状态栏，点击状态栏执行同样的操作。它不会启动或停止远程控制，也不会申请新配对码。

状态栏显示最近一次查询或操作的结果，没有持续刷新。刚打开窗口时显示“未查询”；需要最新结果时再次查询。

| 状态 | 含义与处理 |
|---|---|
| 未查询 | 点击状态栏查询 |
| 等待重载 | 配置已完成，任务结束后重载 |
| 已启动 | 远程控制已就绪，手机可选择主机；首次使用仍需配对 |
| 未启动 | 需要使用手机时运行启动远程控制 |
| `connecting` 或其他状态 | 正在连接或尚未就绪，稍后查询 |
| 操作未完成 | 查看通知中的提示，再查询实际状态 |
| 启动设置已恢复 | 原启动设置已恢复，空闲时重载 |

## 停止远程控制

关闭所选 Codex 的远程控制。桌面聊天和正在运行的任务继续执行，配置及手机配对保留。下次使用只需运行 **启动远程控制**。

此命令用于停止远程控制；停止任务应在 Codex 聊天中操作。

## 恢复 Codex 启动设置（卸载前）

恢复首次启用前保存的 `chatgpt.cliExecutable`：原来未设置时删除该设置，原来有值时还原原值。若启用前使用过其他 wrapper，也会恢复那个 wrapper。

命令会检查当前设置。若已被其他操作修改，会提示并保留当前值；自动更新也不会重新启用已恢复的配置。恢复后，等任务结束再重载窗口并卸载插件。

要直接使用官方默认 Codex，可删除 User Settings 中的 `chatgpt.cliExecutable` 并重载。

## CLI 命令

在 WSL 终端运行，不需要进入某个项目目录。`codex-remote` 是 `scripts/remote.py` 的短命令；没有安装短命令时使用 `python3 /此项目/scripts/remote.py`。

| 命令 | 效果 |
|---|---|
| `codex-remote list` | 列出已启动且可连接的 Codex，无需加载聊天 |
| `codex-remote connect` | 启动远程控制；多个实例需指定 `--pid` |
| `codex-remote pair --open` | 申请新配对码并尝试打开配对页 |
| `codex-remote status` | 查询连接状态，可能附带配对是否完成的结果 |
| `codex-remote disconnect` | 断开手机连接 |

`list` 显示 `childPid`（进程 ID）、`cwd`（启动目录）和 `active`（是否有任务运行）。多个实例时用进程 ID 指定目标：

```sh
codex-remote list
codex-remote connect --pid 12345
codex-remote status --pid 12345
codex-remote disconnect --pid 12345
```

示例 ID 替换为 `list` 中的当前值，重开窗口后可能变化。

成功返回退出码 `0`，业务错误为 `1`，参数错误为 `2`。配对页生成成功而浏览器未打开时仍视为成功，按提示打开页面即可。启用/恢复设置使用插件命令。

## 常见问题

| 提示或情况 | 处理 |
|---|---|
| 未找到可连接的 Codex | 打开官方 Codex 面板后重试；首次启用接入后请先重载窗口 |
| 请先运行“配置远程控制” | 先完成配置，再在任务结束后重载 |
| 另一个 Codex 已连接 | 在原实例停止远程控制，再选择新的实例 |
| 远程控制配置更新失败 | 运行配置远程控制修复，或恢复 Codex 启动设置 |
| 当前设置已被其他操作更改 | 原设置保留，按当前实际配置处理 |
| 浏览器未打开 | 点击复制网页链接，粘贴到电脑浏览器，无需重新申请配对码 |
