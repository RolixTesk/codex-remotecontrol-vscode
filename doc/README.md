## 首次使用

1. 运行 **Codex Remote: 配置远程控制**。
2. 等当前任务结束，运行 **Developer: Reload Window**。
3. 启动官方 Codex，运行 **Codex Remote: 配对手机**，无需打开聊天。
4. 用手机扫码或输入手动码，完成授权。

配对页会尝试自动打开浏览器。未打开时，点击通知中唯一的 **复制网页链接**，粘贴到电脑浏览器查看页面。

## 日常使用

自动连接默认开启，完成手机配对后，启动 Codex 即会自动启动远程控制。已有配对却未自动启动时，手动运行一次 **启动远程控制**，无需重新配对。有多个 Codex 实例时，使用该命令选择实例。

点击状态栏或运行 **查看远程控制状态** 刷新结果。**停止远程控制** 会暂停本次窗口的自动连接；手动启动或重开窗口后恢复。若希望一直手动启动，在设置中关闭 `codexRemote.autoConnect`。

切换实例时，先在原连接运行 **停止远程控制**，再选择目标连接。卸载前运行 **恢复 Codex 启动设置（卸载前）**，空闲时重载后再卸载。

支持 Ubuntu 本地 VS Code、Windows VS Code 通过 WSL 运行 Codex，以及 Remote-WSL 窗口。未登录时可完成配置，使用手机远程控制前需登录。官方扩展升级后会自动更新配置；出现更新提示时，在任务结束后重载。自动更新失败时，可运行 **配置远程控制** 或 **恢复 Codex 启动设置（卸载前）**。
