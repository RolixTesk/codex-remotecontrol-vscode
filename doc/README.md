## 常用流程

首次启用：

1. 在目标 VS Code 窗口运行 **Codex Remote: 启用 / 更新接入**。
2. 等当前 Codex 任务结束，运行 **Developer: Reload Window**，打开原聊天。
3. 运行 **Codex Remote: 连接当前项目**。
4. 首次添加手机时运行 **Codex Remote: 配对手机**，在手机完成配对并选择桌面的同一聊天。

日常使用：打开已接入的项目和聊天，运行 **连接当前项目**；点击状态栏或运行 **查看连接状态** 刷新结果。窗口重载或重开后，再次运行连接命令。

切换连接窗口：在原窗口运行 **断开当前项目**，再在目标窗口连接。卸载插件前运行 **恢复接入前配置（卸载前）**，等任务结束后重载，再卸载。

## 环境与作用范围

当前支持 Windows 侧插件通过 WSL 启动 Linux Codex，以及 Remote-WSL 中插件直接启动 Linux Codex。Windows 原生 `codex.exe` 接入尚未实现。

插件通过已加载聊天定位原 Codex 后端。一个后端进程可以管理多个聊天；Remote 开关作用于整个后端进程，项目选择用于定位进程，不能限制手机只访问该项目。

自动发现进程和聊天已实现；升级后的官方 binary 路径目前通过 **启用 / 更新接入** 更新。自动维护升级路径属于后续规划，当前版本不会自动启用接入、连接或重载窗口。
